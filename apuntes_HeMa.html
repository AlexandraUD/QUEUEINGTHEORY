1.1 Esperanza matemática

Para cualquier variable aleatoria, continua o discreta, la esperanza es el producto interno de la variable y su función de densidad:

\[ E[X] = \langle x, f_X(x)\rangle = \int_{-\infty}^{\infty} x\, f_X(x)\,dx \quad=\ \text{media, valor promedio o primer momento} \]

Variable aleatoria discreta

Si \(X:\Omega\to\mathbb{R}\) toma los valores \(x_1,\dots,x_n\) con probabilidades \(P[X=x_i]=P_i\), la densidad es una combinación lineal de impulsos unitarios desplazados:

\[ f_X(x) = P_1\,\delta(x-x_1) + \cdots + P_n\,\delta(x-x_n) = \sum_{i=1}^{n} P_i\,\delta(x-x_i) \] \[ E[X] = \int_{-\infty}^{\infty} x \sum_{i=1}^{n} P_i\,\delta(x-x_i)\,dx = \sum_{i=1}^{n} P_i \int_{-\infty}^{\infty} x\,\delta(x-x_i)\,dx \]

Por la propiedad de muestreo del impulso, \(\int_{-\infty}^{\infty} g(x)\,\delta(x-a)\,dx = g(a)\), así que \(\int x\,\delta(x-x_i)\,dx = x_i\):

\[ E[X]=\sum_{i=1}^{n} x_i P_i=\mathbf{x}\cdot\mathbf{p}=\mathbf{x}*\mathbf{p}^T \]
  • El producto interno no depende de que la variable sea continua o discreta. En el caso discreto equivale al producto punto entre el vector de valores \(\mathbf{x}\) y el vector de probabilidades \(\mathbf{p}\).
  • Si los dos son vectores fila, en MATLAB se calcula como x*p'. Si son vectores columna, como x'*p.

1.2 Momentos, varianza y desviación estándar

MomentoFórmulaInterpretación
1.º\(E[X]=\int x f_X(x)\,dx\)Promedio, media
2.º\(E[X^2]=\int x^2 f_X(x)\,dx\)Segundo momento; es la varianza cuando la media es cero
3.º\(E[X^3]=\int x^3 f_X(x)\,dx\)Asimetría
4.º\(E[X^4]=\int x^4 f_X(x)\,dx\)Curtosis
\[ \sigma_X^2 = E\big[(X-E[X])^2\big] = E\big[X^2 - 2XE[X] + E^2[X]\big] = E[X^2] - 2E[X]E[X] + E^2[X] \]
\[ \sigma_X^2 = \underbrace{E[X^2]}_{\text{segundo momento}} - \underbrace{E^2[X]}_{\text{promedio}^2} \qquad\qquad \sigma_X = \sqrt{E[X^2]-E^2[X]} \]

\(\sigma_X^2\): varianza · \(\sigma_X\): desviación estándar, relacionada con la precisión.

Ejemplo 2 (ejercicio en clase): ¿cuánto debería pagar un chance por cada peso apostado para que sea un juego justo?

Se apuestan $2000 a dos cifras, así que la probabilidad de ganar es 1/100. \(G\): dinero ganado. Con un premio de $100 000 (50 pesos por cada peso apostado):

\(g\)\(P[G=g]\)
$100 000 − $2000 = $98 0001/100
−$200099/100
\[ E[G] = \$98\,000\cdot\tfrac{1}{100} - \$2000\cdot\tfrac{99}{100} = -\$1000 \]

En promedio el jugador pierde $1000 por apuesta. Para que el juego sea justo (\(E[G]=0\)) con un pago de \(S\) pesos por cada peso apostado:

1.4 Variables aleatorias de una cola

Una cola es el modelo matemático de un sistema de atención: no hay cola si no se presta un servicio. En la M/M/1/∞/∞ hay un único servidor, y los tiempos entre arribos consecutivos y de servicio son exponenciales:

\[ T_{\text{arribo}}\sim\text{Exp}(t;\lambda),\qquad T_{\text{servicio}}\sim\text{Exp}(t;\mu),\qquad E[T_{\text{arribo}}]=\frac{1}{\lambda},\qquad E[T_{\text{servicio}}]=\frac{1}{\mu} \]

\(\lambda\) es la tasa media de arribo y \(\mu\) la tasa media de servicio (en la M/M/1 se exige \(\lambda<\mu\)). De la dinámica de la cola salen cuatro variables aleatorias:

VariableSignificadoValores
\(N_s\)Número de usuarios en el sistema (fila + servicio)\(0,1,2,\dots\)
\(N_w\)Número de usuarios en la línea de espera\(0,1,2,\dots\)
\(T_s\)Tiempo de un usuario en el sistema\(t_s>0\)
\(T_w\)Tiempo de espera de un usuario en la fila\(t_w\ge 0\) (puede no esperar)

Las probabilidades de estado son \(P[N_s=n]=P_n\).

BDistribución de los tiempos de servicioM, G, D
CCantidad de servidores1, 2, 3, …
DTamaño del sistema (línea de espera + servidores)1, 2, 3, …, K, K+1, …, ∞
ETamaño de la población∞, finito

  • M (memoryless, sin memoria): tiempos exponenciales. Servicio \(T\sim \text{Exp}(x;\mu)\); arribos \(T\sim\text{Exp}(x;\lambda)\).
  • G: distribución general (GI: general con tiempos independientes).
  • D: determinístico (degenerado).
  • X: en la sesión 11 se usa X/X/1 para indicar cualquier distribución de arribo y de servicio (3.1).
SistemaDescripción

M/M/1/K/∞/FIFOUn servidor y capacidad K en total: caben como máximo K−1 usuarios en la fila. Si el sistema está lleno, el usuario que llega no entra.

M/M/K/∞K servidores con fila infinita (Erlang C). Si todos están ocupados, el usuario espera.

Con varios servidores la tasa de salida crece con el número de servidores ocupados: \(\mu P_1,\ 2\mu P_2,\ 3\mu P_3,\dots,\ K\mu P_K,\ K\mu P_{K+1},\dots\). Desde K todos están ocupados y la tasa queda en \(K\mu\).

1.6 Actividad 1: modelo matemático de la cola M/M/1

Se trabaja como un proceso de nacimiento (llega alguien: se pasa al estado superior, tasa \(\lambda\)) y muerte (alguien sale: se pasa al estado anterior, tasa \(\mu\)).

Paso 1: diagrama de transición de estados

Cada flecha lleva la tasa multiplicada por la probabilidad del estado de origen.

Paso 2: ecuaciones de estado estacionario

Para cada estado: tasa promedio de salida del estado = tasa promedio de llegada al estado.

EstadoSalidaLlegadaDespeje
0\(\lambda P_0\)=\(\mu P_1\)\(P_1=\frac{\lambda}{\mu}P_0\)
1\(\mu P_1+\lambda P_1\)=\(\lambda P_0+\mu P_2\)\(P_2=\frac{\lambda}{\mu}P_1\)
2\(\mu P_2+\lambda P_2\)=\(\lambda P_1+\mu P_3\)\(P_3=\frac{\lambda}{\mu}P_2\)
⋮⋮⋮⋮
n\(\mu P_n+\lambda P_n\)=\(\lambda P_{n-1}+\mu P_{n+1}\)\(P_{n+1}=\frac{\lambda}{\mu}P_n\)

En el estado 1, \(\mu P_1\) y \(\lambda P_0\) se cancelan por la ecuación del estado 0 y queda \(\lambda P_1=\mu P_2\). Pasa lo mismo en cada estado siguiente: la probabilidad del estado siguiente depende solo del estado actual.

Paso 3: \(P_n\) en función de \(P_0\)

\[ P_2=\tfrac{\lambda}{\mu}P_1=\left(\tfrac{\lambda}{\mu}\right)^2P_0,\quad P_3=\left(\tfrac{\lambda}{\mu}\right)^3P_0,\quad\dots,\quad P_{n+1}=\tfrac{\lambda}{\mu}P_n=\left(\tfrac{\lambda}{\mu}\right)^{n+1}P_0 \]
\[ P_n=\left(\frac{\lambda}{\mu}\right)^n P_0 \]

Paso 4: calcular \(P_0\) (normalización)

\[ \sum_{n=0}^{\infty}P_n=1 \;\Rightarrow\; \sum_{n=0}^{\infty}\left(\tfrac{\lambda}{\mu}\right)^nP_0=1 \;\Rightarrow\; P_0=\frac{1}{\sum_{n=0}^{\infty}A^n}=\frac{1}{S_\infty},\qquad A=\frac{\lambda}{\mu}\ \text{(intensidad de tráfico)} \]

Herramienta: sumar una serie desplazándola

Con la suma \(1+2+\dots+100\): se escribe al derecho y al revés y se suma.

\[ \begin{aligned} S &= 1+2+3+\cdots+99+100\\ S &= 100+99+98+\cdots+2+1\\ \hline 2S &= 101+101+\cdots+101 = 101(100) \;\Rightarrow\; S=5050 \end{aligned} \]

Con una idea parecida se suma la serie geométrica de los primeros \(K+1\) términos: se multiplica por \(A\) y se resta.

\[ \begin{aligned} S_K &= 1+A+A^2+\cdots+A^{K-1}+A^K\\ AS_K &= \phantom{1+{}}A+A^2+\cdots+A^{K-1}+A^K+A^{K+1}\\ \hline S_K-AS_K &= 1-A^{K+1} \end{aligned} \]
\[ S_K=\frac{1-A^{K+1}}{1-A}\quad(A\neq1) \qquad\qquad \lim_{K\to\infty}S_K=S_\infty=\frac{1}{1-A}\quad\text{si } |A|<1 \]

La serie infinita converge solo si \(\lambda/\mu<1\), es decir, \(\lambda<\mu\).

Resultado de la M/M/1

\[ P_0=\frac{1}{S_\infty}=1-A=1-\frac{\lambda}{\mu}\quad(\Rightarrow A=1-P_0) \]
\[ P_n=\left(\frac{\lambda}{\mu}\right)^n\left(1-\frac{\lambda}{\mu}\right) \]

1.7 Tarea 10 (= actividad 1 del trabajo 2): modelo de la M/M/1/K

Se repiten los cuatro pasos para la M/M/1/K. Lo que cambia:

  • Los estados van solo de 0 a K.
  • En el estado K no hay nacimientos: \(\mu P_K=\lambda P_{K-1}\).
  • La suma de normalización es finita (\(S_K\)), así que no se necesita \(\lambda<\mu\): A puede ser menor, igual o mayor que 1.
\[ P_0=\frac{1-A}{1-A^{K+1}},\qquad P_n=\frac{(1-A)A^n}{1-A^{K+1}},\quad n=0,1,\dots,K,\quad A\neq1 \] \[ \text{Caso }A=1:\quad S_K=K+1 \;\Rightarrow\; P_n=\frac{1}{K+1} \]

Si \(\lambda<\mu\) y \(K\to\infty\), se recupera la M/M/1.

2.1 Tiempos y usuarios en la cola

\[ T_s = T_w + T_{\text{servicio}}\;\Rightarrow\; E[T_s]=E[T_w]+\frac{1}{\mu} \]

Las medidas de desempeño son las esperanzas \(E[\cdot]\) de estas variables: \(E[N_s]\), \(E[N_w]\), \(E[T_s]\), \(E[T_w]\), y en sistemas con capacidad limitada, la probabilidad de bloqueo.

2.2 Número promedio de usuarios en el sistema, \(E[N_s]\), en la M/M/1

\(E[N_s]\) es el número promedio de usuarios en el sistema (tamaño promedio de la cola en el sentido amplio). Se aplica la esperanza discreta a \(P_n=A^n(1-A)\):

\[ E[N_s]=\sum_{n=0}^{\infty}n\,P[N_s=n]=\sum_{n=0}^{\infty}n\,A^n(1-A)=(1-A)\sum_{n=0}^{\infty}nA^n \]

Truco de la derivada: como \(\frac{d}{dx}x^n=nx^{n-1}\), se tiene \(nA^n=A\,\frac{d}{dA}A^n\):

\[ E[N_s]=(1-A)A\frac{d}{dA}\underbrace{\sum_{n=0}^{\infty}A^n}_{S_\infty}=(1-A)A\frac{d}{dA}\frac{1}{1-A}=\frac{(1-A)A(-1)(-1)}{(1-A)^2} \]
\[ E[N_s]=\frac{A}{1-A}=\frac{\lambda}{\mu-\lambda}\qquad(\lambda<\mu) \]

2.3 Teorema de Little y medidas de desempeño de la M/M/1

Si al sistema llegan \(\lambda\) usuarios por unidad de tiempo, hay en promedio \(E[N_s]\) adentro y cada uno permanece en promedio \(E[T_s]\). Lo mismo vale solo para la fila:

\[ \lambda=\frac{E[N_s]}{E[T_s]}\qquad\qquad \lambda=\frac{E[N_w]}{E[T_w]} \]

\(\lambda\) es una cantidad de usuarios sobre unidad de tiempo.

Intuición del tablero: si \(E[T_s]=2\) h y \(E[N_s]=68\) km, entonces \(\lambda=68\text{ km}/2\text{ h}=34\) km/h.

MedidaCómo se obtieneResultado M/M/1
\(E[N_s]\)\(\sum n P_n\)\(\dfrac{\lambda}{\mu-\lambda}\)
\(E[T_s]\)Little: \(E[N_s]/\lambda\)\(\dfrac{1}{\mu-\lambda}\)
\(E[T_w]\)\(E[T_s]-E[T_{\text{servicio}}]\)\(\dfrac{1}{\mu-\lambda}-\dfrac{1}{\mu}=\dfrac{\lambda}{\mu(\mu-\lambda)}\)
\(E[N_w]\)Little: \(\lambda E[T_w]\)\(\dfrac{\lambda}{\mu-\lambda}-\dfrac{\lambda}{\mu}=\dfrac{\lambda^2}{\mu(\mu-\lambda)}\)

Paso a paso para \(E[T_w]\), el "tiempo promedio de espera":

\[ \frac{1}{\mu-\lambda}=E[T_w]+\frac{1}{\mu}\;\Rightarrow\;E[T_w]=\frac{1}{\mu-\lambda}-\frac{1}{\mu}=\frac{\mu-\mu+\lambda}{(\mu-\lambda)\mu}=\frac{\lambda}{\mu(\mu-\lambda)} \]

Observaciones

  1. \(\lambda\) debe ser menor que \(\mu\) para que el sistema sea estable (la cola no crece indefinidamente).
  2. Las medidas de desempeño de la M/M/1/∞/∞ quedan determinadas solo por \(\lambda\) y \(\mu\).
  3. Son válidas solo si los tiempos entre arribos y de servicio son exponenciales.

¿Cuánto tiempo, en promedio, tarda un usuario haciendo la fila, si el tamaño promedio de la cola es 15 y la persona que atiende se demora 3 minutos, en promedio, con cada cliente?

2.5 Medidas de desempeño de los sistemas asignados

1) M/M/1/K (cola del grupo)

Un servidor y como máximo K−1 usuarios en la fila. No hay estados mayores que K.

\[ P_n=\frac{(1-A)A^n}{1-A^{K+1}} \]
\[ P_K=P[N=K]=\frac{(1-A)A^K}{1-A^{K+1}}\qquad\longleftarrow\ \textbf{probabilidad de bloqueo} \]

Es la probabilidad de que el sistema esté lleno; el usuario que llega en ese momento queda bloqueado.

  • A puede tomar cualquier valor positivo, menor o mayor que 1.
  • El problema es \(A=1\): la fórmula da \(\frac00\), una indeterminación. Se resuelve desde las ecuaciones originales reemplazando \(A=1\), o con la regla de L'Hôpital. Ese es el punto de partida de la tarea 11.

2) M/M/K/K (Erlang B)

\[ P_n=\frac{\frac{A^n}{n!}}{\sum_{n=0}^{K}\frac{A^n}{n!}}\qquad\qquad P_K=E_{1,K}=\frac{\frac{A^K}{K!}}{\sum_{n=0}^{K}\frac{A^n}{n!}}\ \longleftarrow\ \text{probabilidad de bloqueo} \]

Pregunta del tablero: ¿cómo calcular \(P_{K+1}\) a partir de \(P_K\)?

\[ P_{K+1}=\frac{\frac{A^{K+1}}{(K+1)!}}{\sum_{n=0}^{K+1}\frac{A^n}{n!}}=\frac{\frac{A^K A}{(K+1)K!}}{\sum_{n=0}^{K}\frac{A^n}{n!}+\frac{A^{K+1}}{(K+1)!}} \]

Al dividir numerador y denominador por \(\sum_{n=0}^{K}\frac{A^n}{n!}\) se llega a la recurrencia (este paso no quedó escrito en clase; es lo que pide investigar la tarea 12):

\[ E_{1,K+1}=\frac{A\,E_{1,K}}{K+1+A\,E_{1,K}},\qquad E_{1,0}=1 \]

Arranque visto en clase, con \(K=1\): \(\;P_1=\dfrac{A^1/1!}{A^0/0!+A^1/1!}=\dfrac{A}{1+A}\), que coincide con la recurrencia desde \(E_{1,0}=1\).

Verificado: la recurrencia y la fórmula directa dan lo mismo (con A = 2,5 y K = 3, ambas dan 0,28217).

3) M/M/K/∞ (Erlang C)

K servidores y fila infinita. Requiere \(A<K\).

\[ P_n=\begin{cases}\dfrac{A^n}{n!}P_0 & n<K\\[2mm] \left(\dfrac{A}{K}\right)^n\dfrac{K^K}{K!}P_0 & n\ge K\end{cases}\qquad\quad P_0=\frac{1}{\sum_{n=0}^{K-1}\frac{A^n}{n!}+\frac{K}{K-A}\frac{A^K}{K!}} \]

\(P[T_w>0]\) es la probabilidad de espera, la de que el usuario tenga que hacer fila:

\[ P[T_w>0]=\frac{K}{K-A}\frac{A^K}{K!}P_0=E_{2,K}=\frac{K\,E_{1,K}}{K+A(E_{1,K}-1)} \]

            inicio(i+1) = salida(i);
        end

        tds
        reloj
        inicio
        salida
        espera
    end

3.4 Función cuantil (quantile)

La función cuantil es la inversa de la función de distribución acumulativa. Si \(F_X(x)=P[X\le x]=p\):

\[ Q_X(p) := F_X^{-1}(p) \]

Intuición: si se ordenan los datos de menor a mayor y se dividen en 4 grupos se obtienen los cuartiles (como la clasificación Q1 a Q4 de las revistas científicas); en 10, los deciles; en 100, los percentiles. La función cuantil es esa misma división llevada al nivel infinitesimal. Su variable es una probabilidad \(p\) entre 0 y 1.

Idea de inversa (tablero): si \(y=2x+3\), despejando \(x=\frac{y-3}{2}\). La función cuantil hace lo mismo con la acumulada: dada una probabilidad \(p\), devuelve el valor \(x\) que la acumula.

Función cuantil de la exponencial

Para \(T\sim\text{Exp}(t;\lambda)\):

\[ F_T(t)=\begin{cases}0, & t<0\\ 1-e^{-\lambda t}, & t\ge0\end{cases} \] \[ p=1-e^{-\lambda t}\;\Rightarrow\; e^{-\lambda t}=1-p\;\Rightarrow\; -\lambda t=\ln(1-p)\;\Rightarrow\; \boxed{t=Q_T(p)=-\frac{1}{\lambda}\ln(1-p)} \] 
lambda = 1;
p = linspace(0,0.999,10000);
Q = -log(1-p)/lambda;   % en MATLAB log es logaritmo natural; log10 es base 10

Usos de la función cuantil

  • Describir una variable aleatoria: con la cuantil se recupera la CDF (invirtiendo) y de ella la pdf (derivando), que es el núcleo de las esperanzas.
  • Generar números aleatorios: si \(p\sim\mathcal{U}(0,1)\), entonces \(Q_X(p)\) tiene la misma distribución que \(X\).
  • Revisar si una muestra tiene una distribución particular, por ejemplo con la gráfica Q-Q.

3.5 Método de la transformación inversa

  1. Generar \(p\sim\mathcal{U}(p;0,1)\). En MATLAB: p = rand.
  2. \(Q_X(p)\) es el número aleatorio con la distribución de \(X\).

El propio exprnd de MATLAB usa este método: en su código fuente genera uniformes con rand y calcula r = -mu .* log(rand(...)), con mu = 1/λ. Usa \(p\) en vez de \(1-p\) porque si \(p\) es uniforme entre 0 y 1, \(1-p\) también lo es.

function y = randomexponencial(lambda,m,n)
    y = -log(1-rand(m,n))/lambda;
end

3.6 Gráfica Q-Q (qqplot)

Es la gráfica de los cuantiles de una muestra contra los cuantiles de una referencia. Si no se indica referencia, MATLAB usa la normal estándar. Si los puntos caen sobre la recta, las dos tienen la misma forma de distribución.

% Datos normales contra la normal estándar
muestra = 0 + 1*randn(1,10000);
qqplot(muestra);

% Datos exponenciales (lambda = 4) contra una exponencial de media 1
referencia = exprnd(1,1,1000000);
muestra = randomexponencial(4,1,1000000);
qqplot(muestra,referencia);

Cómo leer una gráfica Q-Q

  • Recta: si los puntos quedan sobre la línea roja punteada, la muestra tiene la distribución de la referencia. Es una prueba visual de bondad de ajuste.
  • Densidad de puntos: donde las cruces están muy juntas hay mucha probabilidad; donde están dispersas, poca. Que se separen de la recta los puntos dispersos de los extremos es normal; preocupa si se separan los del centro, que son los de mayor probabilidad.
  • Datos normales contra la normal estándar: el valor de la recta en x = 0 estima la media μ, y la pendiente estima la desviación σ. En clase, con μ = 1,5 y σ = 2 se leyó 1,48 y una pendiente de 2. Con regresión lineal estos dos valores se estiman con precisión.
  • Datos exponenciales contra Exp(1): la pendiente es λ. Por eso la referencia debe tener parámetro 1.
  • Datos exponenciales contra la normal estándar no dan una recta: así se descarta que sean normales.

4.1 Actividad 2: función mm1k (hecha)

\(P_K\) se estima contando cuántos usuarios llegan y encuentran el sistema lleno:

\[ \hat{P}_K=\frac{\text{número de usuarios bloqueados}}{\text{número total de usuarios que llegan}} \]

Vale porque las llegadas son de Poisson: la fracción de usuarios que ven el sistema lleno es igual a la fracción de tiempo que el sistema pasa en el estado K (propiedad PASTA).

Punto de partida: la función xx1

mm1k conserva la estructura de xx1 (sección 3.1): los mismos nombres tea, tds, reloj, inicio, salida y espera, la misma regla FIFO y el mismo parámetro opcional mostrar. Solo le agrega el control de la capacidad K.

Cómo se sabe si el sistema está lleno

Con un solo servidor y disciplina FIFO, los usuarios admitidos salen en el mismo orden en que entraron, así que sus instantes de salida van en orden creciente. Por eso, cuando llega el usuario n, hay K o más usuarios en el sistema si y solo si el K-ésimo último admitido todavía no ha salido:

\[ \text{sistema lleno}\iff \texttt{salida}[\text{K-ésimo último admitido}]>\texttt{reloj}[n] \]

En el código, el vector admitidos guarda los índices de los usuarios que entraron y a cuenta cuántos son. El K-ésimo último admitido es admitidos(a-K+1) y el último es admitidos(a). Si todavía no hay K admitidos (a < K), el sistema no puede estar lleno.

Código (trabajo2/mm1k.m)

function [Pk] = mm1k(tea,tds,K,mostrar)
% MM1K Simula una cola M/M/1/K y estima la probabilidad de bloqueo.
%   Pk = mm1k(tea,tds,K,mostrar)
%   tea: vector con los tiempos entre arribos consecutivos.
%   tds: vector con los tiempos de servicio de cada usuario.
%   K: capacidad del sistema (servidor + linea de espera), entero positivo.
%   mostrar: si es 1 (valor por defecto) imprime los vectores de la simulacion.
%   Pk: fraccion de usuarios que llegan y encuentran el sistema lleno.
    switch nargin
        case 3
            mostrar = 1;
    end
    if numel(tea) ~= numel(tds)
        error('tea y tds deben tener el mismo numero de elementos.');
    end
    if ~isscalar(K) || K < 1 || K ~= fix(K)
        error('K debe ser un entero positivo.');
    end

    tea = tea(:)';
    tds = tds(:)';
    usuarios = numel(tea);
    reloj = cumsum(tea);
    inicio = NaN(1,usuarios);
    salida = NaN(1,usuarios);
    bloqueado = false(1,usuarios);
    admitidos = zeros(1,usuarios); % usuarios que entraron, en orden de llegada
    a = 0;                         % cantidad de usuarios admitidos

    for i = 1:usuarios
        % Sistema lleno: el K-esimo ultimo admitido aun no ha salido
        if a >= K && salida(admitidos(a-K+1)) > reloj(i)
            bloqueado(i) = true;
        else
            % Disciplina FIFO, igual que en la cola X/X/1 (funcion xx1)
            if a > 0 && salida(admitidos(a)) > reloj(i)
                inicio(i) = salida(admitidos(a));
            else
                inicio(i) = reloj(i);
            end
            salida(i) = inicio(i) + tds(i);
            a = a + 1;
            admitidos(a) = i;
        end
    end
    espera = inicio - reloj;

    Pk = sum(bloqueado)/usuarios;

    if mostrar == 1
        tea
        tds
        reloj
        inicio
        salida
        espera
        bloqueado
    end
end
  • Para los bloqueados, inicio, salida y espera quedan en NaN, porque nunca entran.
  • tea(:)' y tds(:)' convierten las entradas en vectores fila, para que funcione igual si llegan como fila o como columna.
  • Dentro de un ciclo (actividades 3 y 5) se llama mm1k(tea,tds,K,0), igual que xx1(tea,tds,0), para no imprimir millones de valores.
  • Se comparó con la versión anterior de la función en 3000 casos aleatorios y da exactamente lo mismo.
